╔═══════════════════════════════════════════════════════════╗
║  ВАРИАНТ 1: Автоматическая установка (РЕКОМЕНДУЕТСЯ)     ║
╚═══════════════════════════════════════════════════════════╝

Дважды кликните на файл:  install.bat

Или в PowerShell:

.\install.bat


═══════════════════════════════════════════════════════════════


╔═══════════════════════════════════════════════════════════╗
║  ВАРИАНТ 2: Одна команда (установка всего)               ║
╚═══════════════════════════════════════════════════════════╝

Скопируйте ВСЮ строку и вставьте в PowerShell:

python -m pip install torch numpy pandas scikit-learn fastapi uvicorn pydantic python-dotenv python-telegram-bot sqlalchemy aiosqlite loguru requests python-dateutil pytz tqdm ccxt ta scipy --index-url https://download.pytorch.org/whl/cpu


═══════════════════════════════════════════════════════════════


╔═══════════════════════════════════════════════════════════╗
║  ВАРИАНТ 3: Минимальная установка (только бот)           ║
╚═══════════════════════════════════════════════════════════╝

Если хотите только запустить бота БЕЗ AI:

python -m pip install python-telegram-bot loguru sqlalchemy aiosqlite python-dotenv

╔═══════════════════════════════════════════════════════════╗

╚═══════════════════════════════════════════════════════════╝

python main.py bot


═══════════════════════════════════════════════════════════════


╔═══════════════════════════════════════════════════════════╗
║  ПРОВЕРКА УСТАНОВКИ                                       ║
╚═══════════════════════════════════════════════════════════╝

Вставьте эти команды по одной:

python -c "import telegram; print('OK: Telegram')"
python -c "import loguru; print('OK: Loguru')"
python -c "import sqlalchemy; print('OK: Database')"

Если все показали "OK" - можно запускать бота!


═══════════════════════════════════════════════════════════════


╔═══════════════════════════════════════════════════════════╗
║  ЧТО ДАЛЬШЕ?                                              ║
╚═══════════════════════════════════════════════════════════╝

1. Установите пакеты (выберите вариант выше)

2. Запустите бота:
   python main.py bot

3. Найдите бота в Telegram

4. Отправьте /start
