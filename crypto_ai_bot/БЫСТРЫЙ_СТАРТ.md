## 📱 Как настроить Telegram Mini App

### Локальное тестирование

1. **Запустите API:**
   ```bash
   python main.py api
   ```

2. **Откройте веб-файлы:**
   - Просто откройте `webapp/index.html` в браузере
   - Или используйте локальный сервер:
     ```bash
     cd webapp
     python -m http.server 8080
     ```
   - Откройте http://localhost:8080

### Для продакшена

1. **Загрузите `webapp/` на хостинг** (Vercel, Netlify, GitHub Pages)

2. **Обновите URL в боте:**
   - Откройте [@BotFather](https://t.me/botfather)
   - Отправьте `/mybots`
   - Выберите вашего бота
   - Bot Settings → Menu Button
   - Установите URL вашего Mini App

3. **Обновите API URL в `webapp/app.js`:**
   ```javascript
   const API_BASE_URL = 'https://ваш-сервер.com/api/v1';
   ```

## 🔧 Решение проблем

### "ModuleNotFoundError: No module named 'torch'"

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

### "TELEGRAM_BOT_TOKEN not set"

Проверьте файл `.env`:
```
TELEGRAM_BOT_TOKEN=8380851959:AAFKX1nmlTDDTi9d-rUFBXDHxV6zW4opjHk
```

### "Model not found"

Сначала обучите модель:
```bash
python main.py train-single --symbol BTCUSDT --timeframe 1h
```

### Бот не отвечает

1. Проверьте что процесс запущен
2. Проверьте токен в `.env`
3. Проверьте интернет-соединение

### API не работает

1. Проверьте что порт 8000 свободен
2. Запустите с другим портом:
   - Измените `API_PORT=8001` в `.env`
   - Или в `config.py`
