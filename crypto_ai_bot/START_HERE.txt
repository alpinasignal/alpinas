ВАРИАНТ 3: С ОБУЧЕНИЕМ МОДЕЛИ (реальные предсказания)

═══════════════════════════════════════════════════════════════

1. Установите зависимости:
   pip install -r requirements.txt

2. Обучите одну модель для теста (~10 минут):
   python main.py train-single --symbol BTCUSDT --timeframe 1h

3. Получите предсказание:
   python main.py predict --symbol BTCUSDT --timeframe 1h

4. Запустите API (в первом терминале):
   python main.py api

5. Запустите бота (во втором терминале):
   python main.py bot

6. Протестируйте в Telegram!
